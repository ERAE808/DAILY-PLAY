# DAILY PLAY 버전별 변경 이력 · 1.0~2.7.8

사용자가 확인할 수 있는 기능과 동작의 변화를 버전별로 정리했습니다. 같은 기능의 반복 수정은 합쳐 설명했습니다. 아래 버전 구분은 변경 이력이며, 모든 버전의 실행파일이 GitHub에 공개되었다는 뜻은 아닙니다. 실제 받을 수 있는 파일과 해당 파일의 지원 범위는 [Releases](https://github.com/ERAE808/DAILY-PLAY/releases)에서 확인하세요.

1.0부터 2.7.8까지 기록이 확인되는 21개 버전을 수록했습니다. 별도 변경 기록이 없는 중간 버전 번호는 만들지 않았습니다. 현재 화면인식 지원 범위와 제한은 최신 릴리스 설명을 우선합니다.

## 2.7.8

- 명조: 워더링 웨이브 화면인식 추가. 체크리스트에서 접속·출석, 웨이브 플레이트 사용, 솔라리스 활약도, 금일 아침방송, 주간 인기방송, 군가의 중주, 주간 여행, 심경 구역, 재생 해역, 선약 방송국의 진행도를 반영합니다. 화면인식은 동의 후 켤 수 있으며 기본값은 OFF입니다.
- 명조 체크리스트에 진행 수치와 수동 증감 조작을 추가했습니다. 재생 해역은 스테이지와 수령한 보상을 따로 표시합니다. 엔드필드 프로토콜 통행증에는 시즌명, 레벨, 남은 기간을 표시합니다.
- 화면 감지 주기에 50ms 선택지를 추가했습니다. 새 설정의 기본값은 500ms이며, 이전에 저장된 2초는 500ms로 읽습니다.
- 인식 결과를 저장하는 동안 다음 관찰을 처리할 수 있도록 개선했습니다. 엔드필드·명조는 연속 관찰에서 최신 자동 상태를 저장하고, 사용자의 수동 변경을 우선합니다. 쓰기에 실패하면 마지막 정상 저장 상태를 복원합니다.
- 다섯 게임의 공식 업데이트·점검 정보를 알림판, 미니바와 달력에서 확인할 수 있습니다. 날짜만 공개됐으면 확인된 날짜를 표시합니다. 예정 종료가 확인된 점검 공지는 완료 표시가 있으면 24시간, 없으면 48시간 뒤 정리합니다.
- 트릭컬 엘리아스 프론티어의 공식 전투 일정을 특별퀘스트에 연결했습니다. 스페셜 픽업의 선택 가능 사도와 확인된 모집 일정을 표시합니다.
- 설정에서 미니바 바로가기를 만들면 현재 사용자의 바탕화면과 시작 메뉴에 각각 하나씩 생성합니다. 다시 만들면 두 바로가기를 갱신합니다.

## 2.7.7

- 명일방주: 엔드필드 화면인식 추가. 체크리스트에서 접속·출석, 이성 소모, 일일 활약도, 크레딧 거래소, 공장 생산물 판매와 프로토콜 통행증 진행을 체크리스트에 반영할 수 있습니다. 화면인식은 사용자 동의 후 켤 수 있으며 기본값은 OFF입니다.
- 지원 게임에서 연속으로 도착한 화면인식 결과를 순서대로 반영하고, 저장이 완료된 뒤 진행도를 갱신하도록 개선했습니다.
- 명조·젠레스 존 제로의 공식 일정 조회를 보강했습니다. 명조 출석, 트릭컬 카드 뽑기, 엔드필드 단계별 개방 일정의 누락을 보완하고 엔드필드의 일부 전투 이벤트를 특별퀘스트에 반영합니다.
- 엔드필드 일일퀘스트에 활약도와 보상 수령 점수, 누적 이성 소모를 표시합니다. 최대 저장량을 초과해 보유한 이성도 소모량 계산에 반영합니다.
- 젠레스 존 제로의 비디오가게 경영 완료, 커피 배터리 보상 및 일일 활약도 판독을 보완했습니다. 배터리 수동 설정을 유지하면서 활약도를 반영합니다.
- 소녀전선2: 망명의 로비 접속·출석 판독을 보완했습니다. 흙먼지 전선 특별퀘스트는 기존 이벤트 일정이 정리된 뒤 한 시간 더 표시되며, 다음 회차는 실제 시작 시각에 생성됩니다.
- 게임별 공식 점검 시각을 홈과 미니바에 표시하고, 점검 종료 후 확인된 픽업을 현재 픽업으로 전환합니다. 달력에서 이어지는 픽업을 각 기간에 표시하고, 후속 공지에 정확한 종료 시각이 나오면 같은 일정에 반영합니다. 후속 응답에 날짜나 시각이 빠져도 이미 확인한 픽업 기간을 유지합니다.
- 미니바에서 픽업 이름과 남은 시간, 진행 바의 정렬을 개선했습니다. 달력과 설정을 반복해서 열거나 바꿀 때 중복 갱신을 줄였습니다.

## 2.7.6

- 제품 폴더 전체를 압축 해제하여 실행하는 ZIP 구성을 마련했습니다. ZIP의 실행 경로와 기록 위치를 이전 실행 방식과 분리했습니다.
- 같은 Windows 계정에서 ZIP 제품 폴더를 교체해도 별도 기록 위치를 사용하도록 구성했습니다. 실행 파일과 기록의 복구 절차를 안내합니다.
- 공개 버전 확인에서 ZIP 다운로드를 지원하고 기존 EXE 형식과의 호환을 유지했습니다.
- 한글·공백이 포함된 경로의 바로가기 생성과 재생성 처리를 수정했습니다. 같은 이름의 다른 바로가기는 덮어쓰지 않습니다.
- 화면인식 자동반영의 게임 화면 처리 안내와 동의 문구를 정리했습니다. 기본 OFF와 사용자의 켜기·끄기를 유지합니다.
- 엔드필드 이벤트의 한국 시간 기준 시작 시각을 보정하고, 실제 플레이 기간과 별도 교환 마감을 나누었습니다.
- 공식 점검 전환과 일정 정정을 반영하고, 같은 공지가 다른 식별자로 수집되어도 사용자가 삭제한 같은 회차 일정이 다시 추가되는 경우를 줄였습니다.
- 행사 예고·영상 안내·종료된 증정 정보를 진행 중인 게임 일정과 구분했습니다.

## 2.7.5

- 소녀전선2 로비에서 접속·출석을 먼저 판독하도록 조정했습니다. 젠레스 일일 판독이 관련 없는 주간 항목의 수동 우선 설정에 막히던 경우를 수정했습니다.
- 두 지원 게임의 화면인식 반영 처리를 분리하고, 완료 표시가 저장 결과와 맞도록 조정했습니다.
- 저장이 중단된 경우 유효한 마지막 정상 기록에서 복구하는 처리를 보완했습니다.
- 종료 시각이 확정된 이벤트·업데이트·픽업은 종료 후 24시간 뒤 정리합니다. 날짜만 있는 종료와 별도 교환 마감, 종료 미정 상태를 구분합니다.
- 오래된 공지와 예정 자료가 최근 정정을 덮거나 삭제한 일정을 되살리는 경우를 방지하도록 보완했습니다.
- 공식 이벤트를 게임 내·온라인·오프라인 일정으로 구분하고, 특별 방송·현장 행사·예매·모집·코드 교환을 따로 표시하도록 보완했습니다.
- 트릭컬 공연 일정과 회차, 당첨자 주소 제출 등 별도 마감 시각의 수집을 보완했습니다.
- 트릭컬 주말 콘텐츠의 진행 기간과 보상 수령 기간을 따로 반영하고, 공식 수정 내용을 기존 일정에 갱신합니다.
- 공식 공지 조회 범위와 오류 구분을 보완하고, 같은 제목의 다른 회차를 분리했습니다.
- 엔드필드 공지 게시 시각을 점검 시각으로 잘못 읽는 경우와 시작 시각이 생략된 점검 연장 처리를 수정했습니다.
- 명조·엔드필드·트릭컬·젠레스·소녀전선2의 일정 정정을 반영했습니다. 사용자가 우선 적용한 값은 보존합니다.
- 온라인 조회 성공과 보관 자료 사용을 구분해 최근 온라인 성공 시각을 표시하도록 보완했습니다.
- 미니바 픽업에 시작·종료가 확인되면 경과율을 표시하고, 종료 미정·예정 정보는 구분합니다.
- 점검 완료 공지에 실제 종료 시각이 있으면 연동된 개방 일정에 반영하고, 예정 시각만 있는 경우에는 추정 상태로 표시합니다.
- 알림판과 미니바의 같은 화면 갱신에서 중복 처리를 줄였습니다.
- 새 버전 알림을 닫으면 같은 한국 날짜에는 자동 안내를 반복하지 않으며 다음 날 다시 안내합니다. 같은 버전의 자동 알림을 숨기는 선택과 수동 확인을 제공합니다.
- 미니바의 버전 버튼에서 알림창을 다시 열 수 있으며, 다운로드·알림 숨김·닫기 버튼과 문구를 정리했습니다.

## 2.6

- 앱 시작과 설정에서 새 공개 버전을 확인하고 다운로드 페이지를 안내하는 기능을 추가했습니다.
- 공개 변경 안내는 GitHub 릴리스에서 확인하도록 정리했습니다.
- 공식 업데이트 영상이 나중에 게시돼도 공지에 명시된 점검 시각을 유지합니다.
- 젠레스·소녀전선2 화면인식의 캡처·판독·진행도 반영 처리를 나누고 공통 감지 주기를 조정했습니다.
- 두 게임의 지원 화면 탐색과 접속·출석 판독 순서를 보완하고, 인식 진행도 저장 상태를 표시합니다.
- 자동 완료 항목을 수동 해제할 때 저장 오류로 앱이 종료되던 문제를 수정했습니다. 같은 상태의 반복 저장도 줄였습니다.
- 색상 테마에서 창·카드·글자·버튼·선택 탭과 게임 이름·미니바·달력의 표시 색을 미리 보고 변경할 수 있습니다.
- 색조·채도·밝기를 조절하는 색 선택기를 추가했습니다.
- 미니바·알림판·바로가기·자동 시작의 실행 경로를 정리하고, 필수 실행 파일이 없으면 안내 후 중단합니다.
- 처음 수집한 일정은 기본 목록에 반영하고 이후 추가되는 일정부터 신규 알림을 표시합니다.
- 마감 알림을 켜거나 시간을 바꿀 때 이미 지난 알림이 한꺼번에 표시되는 문제를 수정했습니다.

이 이력에는 2.6 EXE 배포 이후의 후속 변경도 포함됩니다.

## 2.5

- 트릭컬 픽업·테마극장 수집 범위를 넓히고 후속 점검 공지의 개방 예정·실제 시작 시각을 반영합니다.
- 엔드필드·소녀전선2·젠레스·명조의 점검 후 개방 일정에 공식 후속 공지와 점검 연장을 반영하도록 보완했습니다.
- 소녀전선2 이벤트 기간 정정을 같은 갱신의 특별퀘스트에도 반영합니다.
- 실행 경로를 정리하고 첫 실행의 중복 준비 작업을 줄였습니다. 실행 중 창 재호출과 종료 요청 처리도 조정했습니다.
- 미니바 탭 전환의 중복 계산을 줄이고, 알림판·신규 일정 확인 창을 닫은 뒤의 저장 처리를 화면 처리와 분리했습니다.
- 체크·해제 직후 완료 문구와 색을 갱신하도록 조정했습니다.
- 자동 관리 복귀와 설정 저장 시 불필요한 전체 화면 재구성을 줄였습니다. 시작 직후 자동 갱신은 마지막 시도와 설정 주기를 반영합니다.

## 2.4

- 트릭컬 공식 공지에서 신규 사도 픽업과 테마극장 일정을 자동으로 갱신합니다.
- 저장 오류가 발생하면 마지막 정상 저장 상태로 복구하고 실패 상태를 표시하도록 보완했습니다.
- 소녀전선2 변경추진을 영역돌파·위상충돌로 나누고 특별퀘스트 완료 상태와 연동합니다.
- 소녀전선2 지원 화면의 공헌도·진행도 판독과 특별퀘스트 수치 표시를 보완했습니다.
- 흙먼지 전선 특별퀘스트를 이벤트 일정과 연결하고 티켓·개인 성과·개인 보급·서클 성과·서클 보급 항목을 표시합니다.

## 2.3

- 미니바 진행도 집계와 반복 조회의 중복 작업을 줄였습니다.
- 시작 준비와 게임 목록 조회, 체크 직후 화면 갱신, 종료 중 화면 갱신을 정리했습니다.
- 설정·달력의 창 위치 저장을 묶어 처리하고 게임 화면 전환의 반복 구성을 줄였습니다.
- 반복 퀘스트를 체크하면 관련 카드 위주로 갱신하고, 위치가 같은 상세창을 닫을 때 불필요한 저장을 생략합니다.
- 게임 선택만 바꿀 때 별도 저장을 줄이고, 진행도 저장과 복구 기록 조회의 중복 처리를 줄였습니다.
- 체크 표시·저장·달력 갱신 순서를 조정하고, 연속 갱신 요청을 묶어 처리합니다.
- 알림판을 닫을 때의 창 설정 저장과 체크·해제의 디스크 저장을 화면 처리에서 분리했습니다.

## 2.2

- 엔드필드의 일부 도전 콘텐츠를 특별퀘스트로 정리하고 기간·남은 시간·달력 표시를 연결했습니다. 상시 콘텐츠는 종료 없음으로 구분합니다.
- 온라인 갱신 후 특별퀘스트 분류, 수동 수정과 완료 기록을 보존하고 같은 진행도의 중복 일정을 정리합니다.

- 공식 영상 목록 연결 실패 시 공개 영상 정보로 보완하도록 조정했습니다.
- 사용자가 삭제한 일정이 다른 출처를 통해 재등록되는 경우를 방지하도록 보완했습니다.
- 일정 수정·삭제를 복구 기록에도 반영하고 기존 완료 기록을 보존합니다.
- 반복 조회·다운로드·설정 저장과 중복 화면 처리를 줄였습니다.
- 외부 자료 연결의 주소 검증을 강화했습니다.
- 신규 알림바 전체를 눌러 상세를 확인하고 두 화면의 확인 상태를 공유합니다.

- 오래되거나 우선순위가 낮은 자료가 최근 버전 정보를 덮는 경우를 방지합니다.

- 자동 갱신 후 중복 일정을 합칠 때 수동 수정값을 보존합니다.
- 소녀전선2 점검 후 픽업의 진행 상태와 특별퀘스트 분류를 보완했습니다.

- 공식 원문에 명시된 업데이트 날짜를 달력에 표시합니다.
- 리소스 절약·균형·빠른 반응 설정을 추가했습니다.
- 창을 열 때 중복 구성을 줄이고, 선택 일정 보기에서는 진행 기록을 숨기고 기간 막대를 여러 줄로 배치합니다.
