# 사용 기술·AI 활용·공개 범위

[처음으로](../README.md) · [변경 이력](CHANGELOG.md)

이 문서는 사용 기술과 공개 원칙을 설명합니다. 현재 제공 기능, 배포 버전, 향후 계획을 구분합니다.

## ChatGPT AI 활용

DAILY PLAY는 **ChatGPT AI를 활용하여 개발한 프로그램**입니다. 공개할 내용과 제품의 변경 방향은 개발자가 결정합니다. AI 활용 사실은 보안 인증이나 오류 없는 동작을 보장하는 표기가 아닙니다.

## Velopack을 사용하는 부분

| 구분 | 사용 범위 |
|---|---|
| 이전 설치형 패키지 | 패키지 제작, 설치형 앱 초기화와 설치 상태 확인 |
| 2.7.6 폴더형 ZIP | Velopack 라이브러리·업데이터를 포함하거나 실행하지 않음. ZIP 생성에는 .NET 압축 라이브러리 사용 |
| 2.7.6 공개 버전 안내 | 앱 자체 기능으로 GitHub Releases의 새 버전과 다운로드 페이지 안내 |
| 향후 자체 업데이트 | Velopack을 이용한 앱 내 다운로드·적용 기능 개발 예정. 현재 제공 기능 아님 |

예전 설치형에서의 Velopack 사용이 현재 공개 2.6 EXE 또는 2.7.6 ZIP에 자체 업데이트가 들어 있다는 뜻은 아닙니다.

## 사용자에게 공개하는 정보

- 버전별 사용자 기능 변경 이력과 현재 지원 범위
- 사용 언어·프레임워크·도구 및 ChatGPT AI 활용 사실
- 실행 요구사항과 개인정보를 제거한 개발환경 요약
- 기록 저장 위치, 화면인식 동의·끄기, 외부 통신 목적
- 배포 파일명·크기·SHA-256과 서명 여부
- 사용자가 알아야 할 제한과 미구현 상태를 분명히 표시한 개발 방향

계정명·개인 경로·장치 식별자·토큰·쿠키·비밀번호·개인 기록·원본 사진·OCR 원문·내부 작업 문서와 검사 자료는 공개하지 않습니다. 2.7.6 ZIP에는 저장·동기화·화면인식을 포함한 실행용 PowerShell 원문이 포함됩니다. 파일 이름이나 압축 형식만으로 공개 가능 여부를 판단하지 않습니다.

## 실행용 스크립트 공개 범위

이번 2.7.6 ZIP에는 실행에 필요한 PowerShell 스크립트 61개가 원문으로 포함됩니다. 별도 색상 함수 파일이나 전체 개발 원본·개발 도구·내부 작업 자료는 게시하지 않습니다. 제작자가 권리를 보유한 부분의 이용 조건은 [무료 배포·이용 안내](LICENSE-NOTICE.md)를 따릅니다.

## 2.7.6의 정보 처리와 제한

- ZIP용 기록은 `%LOCALAPPDATA%\DailyPlay.Folder.State`에 제품 폴더와 별도로 보관합니다. 이전 공개 2.6 기록과 자동 병합하지 않습니다.
- 화면인식은 기본 OFF이며 사용자가 동의해 켤 수 있습니다. 지원 화면을 PC에서 판독하며 수동 수정과 자동 관리 복귀를 제공합니다.
- 일정 조회에는 공개 웹 자료를 사용하고, 버전 확인에는 GitHub Releases API를 사용합니다. 사이트는 접속 과정에서 IP 주소·접속 시각 등 통신 정보를 받을 수 있습니다.
- 실행 파일과 PowerShell 스크립트는 미서명입니다. 인터넷 출처 표식이 남은 미서명 스크립트는 실행 정책에 따라 차단될 수 있습니다. 온라인 평판 및 그 조건의 실제 앱 실행은 확인되지 않았습니다.
- 화면 배율·해상도·게임 화면 변경에 따라 인식이 실패하거나 잘못 읽을 수 있습니다. 모든 게임과 모든 화면을 지원하지 않습니다.

현재 2.7.6의 상세 내용은 [사용 안내](USAGE.md)와 [개인정보·통신 안내](PRIVACY.md)를 확인하세요.
