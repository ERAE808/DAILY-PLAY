# DAILY PLAY 2.7.8 개인정보·권한·외부 통신 안내

[처음으로](../README.md) · [사용 안내](USAGE.md)

대상은 `DAILY-PLAY-2.7.8.zip`입니다. 이 안내는 제품의 저장·통신 구성에 관한 설명이며 외부 보안 인증이나 모든 실행 상황의 통신 계측 결과를 뜻하지 않습니다.

## PC에 보관하는 정보

완료 여부·진행 수치·회차·추가 항목·수동 우선값·게임 순서·화면 및 알림 설정·수집 일정·조회 상태·화면인식 동의와 반영 진행도·복구 자료를 로컬에 보관합니다.

- 기록·설정과 내부 복구 자료: `%LOCALAPPDATA%\DailyPlay.Folder.State`
- 명시적 복원 시 보존하는 이전 기록: `%LOCALAPPDATA%\DailyPlay.Folder.Backups`
- 직접 내보낸 기록 묶음: 사용자가 선택한 위치
- 추가 데이터 연결 설정: 제품 구성의 `app\sync-sources.json`

기록은 JSON 등 일반 로컬 파일을 사용하며 별도 암호화하지 않습니다. Windows 계정·파일 접근 권한을 관리하고 개인 기록을 공개 게시하지 마세요. 앱 종료나 제품 폴더 삭제만으로 별도 기록이 지워지지는 않습니다.

## 화면인식

기본 OFF이며 지원 게임과 동의를 확인한 뒤 켤 수 있습니다. 게임 프로세스·전면 창을 확인하고 게임 화면의 전체 또는 지정 영역에서 진행도 판독에 필요한 정보를 처리합니다. Windows OCR로 PC 안에서 판독합니다.

화면에는 UID·닉네임 등 개인정보가 함께 보일 수 있으며 일부 알려진 영역을 가리는 처리가 모든 화면의 개인정보 제거를 보장하지는 않습니다. 판독 결과의 진행도·반영 상태는 체크리스트 기록에 저장될 수 있습니다. 자동반영 경로에서 원본 화면·OCR 원문을 외부 업로드하는 기능은 제공하지 않습니다.

**설정 → 게임 화면인식 → 화면인식 자동반영 OFF**로 끌 수 있습니다. 상태는 다음 실행에도 유지됩니다. 인식을 끄는 것과 온라인 일정 조회를 끄는 것은 별개입니다.

## 외부 통신

온라인 자동 갱신·수동 조회·관련 일정 조회는 공개 웹 자료를 요청합니다. 주요 대상은 쿠로게임즈·HoYoverse·엔드필드 공식 사이트, Steam 공식 공지, 네이버 게임 라운지, 픽업캘린더와 공식 YouTube 자료입니다. 사용자가 지정한 추가 HTTPS 데이터 주소와 직접 누른 원문 링크도 사용할 수 있습니다.

새 공개 버전 확인에는 `api.github.com`의 `ERAE808/DAILY-PLAY` Releases API를 사용하며, 다운로드 페이지와 문제 제보는 GitHub에서 제공합니다. 버전 조회가 앱 내 자동 설치를 의미하지는 않습니다.

외부 서비스는 연결 과정에서 IP 주소·접속 시각·요청 URL·User-Agent 등의 정보를 받을 수 있습니다. 원문을 브라우저에서 열면 해당 브라우저와 사이트의 로그인·쿠키·개인정보 정책이 적용됩니다. 추가 데이터 URL에 인증정보나 개인정보를 넣지 마세요.

일정 자동 갱신을 끄면 주기 조회를 중지할 수 있습니다. 수동 조회·원문 링크 열기·별도의 버전 확인까지 전부 차단하는 네트워크 스위치는 아닙니다.

## 권한과 보관

제품 폴더·현재 사용자의 기록 위치에 필요한 쓰기 권한을 사용하며, 화면인식을 켜면 창 조회·캡처 기능을 사용합니다. 로그인 시 자동실행은 사용자가 선택합니다. 관리자 권한 강제 실행이나 보안 기능 해제를 사용 절차로 요구하지 않습니다.
