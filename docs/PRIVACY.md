# 개인정보·권한·외부 통신 안내

[처음으로](../README.md) · [사용 안내](USAGE.md)

대상: 공개 `DAILY-PLAY-2.6.exe` · 확인일: 2026-11-05 KST.

이 문서는 현재 공개 파일의 기술적 동작을 설명합니다. 파일의 SHA-256과 내부 파일을 대조해 확인했으며, 실행 중 전체 네트워크 트래픽을 계측하거나 외부 보안 감사를 수행한 결과는 아닙니다. 다른 버전은 동작이 달라질 수 있습니다.

## PC에 저장하는 정보

| 항목 | 목적·위치 |
|---|---|
| 완료 여부·진행 수치·회차·사용자가 추가한 항목 | 체크리스트 유지. 실행 폴더의 `data` |
| 수동 수정·우선 적용 상태, 게임 순서, 표시·창·알림 설정 | 다음 실행에도 사용자의 선택 유지. `data` |
| 수집한 일정·출처·조회 상태와 관련 캐시 | 일정 표시와 자동 갱신. `data` |
| 화면인식 설정·동의 상태와 반영된 진행도 | 자동반영 제어와 체크리스트 유지. `data` |
| 백업·복구용 파일과 저장 저널 | 저장 실패 등에 대비한 기록 복구. `data` 내부 |
| 사용자가 지정한 추가 데이터 URL | 해당 공개 데이터 조회. `app\sync-sources.json` |
| 사용자가 직접 내보낸 인식 결과 | 선택한 저장 위치. 자동 업로드되지 않음 |

이 배포판의 실행 폴더는 `%LOCALAPPDATA%\DailyPlayPortable\2.6`입니다. `data\planner.json`과 관련 백업·복구 자료에는 개인 사용 기록이 포함되므로 공개 게시하지 마세요.

앱의 확인된 저장 경로는 JSON 등 일반 로컬 파일을 사용하며 별도 암호화를 적용하지 않습니다. PC의 다른 사용자가 접근하지 못하도록 Windows 계정과 파일 접근 권한을 관리하세요.

## 화면인식에서 처리하는 정보

- 기본 OFF이며, 사용자가 대상 게임과 화면인식·연동을 선택하고 동의한 뒤 켤 수 있습니다.
- 게임 실행 여부와 전면 창을 확인하고, 대상 게임 화면의 전체 또는 지정 영역에서 진행도 판독에 필요한 정보를 처리합니다.
- Windows OCR을 사용해 **PC 안에서** 문자를 읽습니다. 확인한 자동인식 경로에는 클라우드 OCR 호출이 없습니다.
- 화면에는 닉네임·UID 등 개인 정보가 함께 보일 수 있습니다. 알려진 일부 UID 영역을 가리는 처리가 있지만, 모든 화면의 개인 정보가 가려진다고 보장하지 않습니다.
- 확인한 자동인식 경로는 원본 화면·OCR 원문을 파일로 자동 저장하거나 외부 서버로 전송하지 않습니다. 판독으로 얻은 진행도와 반영 상태는 체크리스트에 저장될 수 있습니다.
- 인식 결과를 직접 내보내는 기능은 사용자가 지정한 위치에 결과 파일을 만듭니다. 제보 전에 내용을 확인하세요.

**설정 → 게임 화면인식 → 화면인식 자동반영 OFF**로 끌 수 있습니다. OFF 시 수집·판독 중지 처리가 호출됩니다. 켜기·끄기 상태는 다음 실행에도 유지됩니다. 화면인식 OFF가 온라인 일정 조회까지 끄는 것은 아닙니다.

## 외부로 접속하는 경우

일정 자동 갱신, 수동 새로고침, 관련 이벤트 정보 조회 시 공개 웹 자료를 요청합니다. 설정·게임·기능에 따라 아래 대상 중 일부에 접속합니다.

| 대상 | 목적 |
|---|---|
| `www.pickupcal.com` | 픽업·이벤트 일정 데이터 조회 |
| `store.steampowered.com` | 공식 Steam 공지·이벤트 자료 조회 |
| `comm-api.game.naver.com` | 게임 공식 네이버 라운지 공지 조회 |
| `endfield.gryphline.com` | 엔드필드 공식 공지 조회 |
| `www.youtube.com` | 게임 공식 채널의 영상 목록·설명 조회 |
| 사용자가 추가 데이터 연결에 입력한 HTTPS 주소 | 사용자가 선택한 일정 데이터 조회 |
| 공지·영상의 원문 링크 대상 | 사용자가 링크를 누르면 브라우저에서 열기 |

이 목록은 기본 조회 대상과 사용자 지정 경로를 설명한 것입니다. 응답의 리디렉션에 따라 최종 접속 호스트가 달라질 수 있으며, 원문 링크를 브라우저로 열 때는 해당 사이트의 정책과 브라우저 설정이 적용됩니다.

확인한 일정 수집 코드는 공개 URL에 GET 요청을 보내며, 체크 기록·원본 화면·OCR 원문을 요청 본문에 담아 업로드하는 경로는 확인되지 않았습니다. 앱의 일정 조회에서는 쿠키와 Windows 기본 자격 증명을 사용하지 않도록 설정되어 있습니다.

외부 서비스는 통신 과정에서 **IP 주소, 접속 시각, 요청 URL·쿼리, User-Agent 등의 접속 정보**를 받을 수 있습니다. 별도 게임 계정 로그인 정보를 입력할 필요는 없습니다. 추가 데이터 URL에 토큰·비밀번호·개인 정보를 넣지 마세요. 브라우저에서 원문을 열면 브라우저의 로그인·쿠키가 사용될 수 있습니다.

온라인 일정의 주기적 조회는 설정의 **온라인 일정 자동 갱신**을 끄고 저장해 중지할 수 있습니다. 수동 조회·링크 열기 및 화면인식 관련 이벤트 정보 조회까지 모두 차단하는 네트워크 차단 스위치는 아닙니다.

GitHub는 실행파일 다운로드와 문제 제보에 사용됩니다. 이 공개 2.6 파일에는 후속 개발본의 GitHub 공개 버전 자동 조회 기능이 포함되어 있지 않습니다.

## 권한과 자동실행

- 실행파일·기록 저장을 위해 현재 사용자 폴더에 쓰기 권한이 필요합니다.
- 화면인식을 켜면 게임 프로세스·창 상태 확인과 화면 캡처 API를 사용합니다.
- 온라인 자료 조회에는 네트워크 접근이 필요합니다.
- 로그인 시 자동실행을 선택하면 현재 사용자의 시작프로그램 폴더에 `DailyPlay-GameChecklist.lnk`를 만듭니다. 해제하면 해당 항목을 제거합니다.
- 공개 실행기는 사용자별 경로를 사용합니다. 관리자 권한 강제 실행이나 보안 기능 해제를 사용 절차로 요구하지 않습니다.

## 보관·삭제·제보

진행 기록은 다음 실행에도 사용하기 위해 로컬에 남습니다. 앱 또는 내려받은 EXE를 종료·삭제해도 기록이 자동 삭제되지는 않습니다. [사용 안내의 제거 절차](USAGE.md#제거)에 따라 종료·백업 후 해당 버전 폴더를 삭제할 수 있습니다. 별도 내보내기·백업 파일은 사용자가 저장한 위치에서 관리해야 합니다.

문제 제보 시 기록 폴더 전체나 원본 게임 사진을 첨부하지 마세요. 필요한 오류 문구와 재현 순서를 먼저 전달하고, UID·닉네임·경로·토큰 등이 노출되지 않는지 확인하세요.
