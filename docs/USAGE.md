# DAILY PLAY 사용 안내

[처음으로](../README.md) · [개인정보·통신 안내](PRIVACY.md)

대상: Releases에 게시된 `DAILY-PLAY-2.6.exe`. 확인일: 2026-11-05 KST.

## 다운로드와 실행

[2.6 릴리스](https://github.com/ERAE808/DAILY-PLAY/releases/tag/DAILYPLAY)의 Assets에서 `DAILY-PLAY-2.6.exe`를 받습니다. EXE를 더블클릭하면 파일 준비 후 미니바를 실행합니다.

이 파일은 별도 설치 마법사 없이 파일을 푸는 실행파일입니다. 실행파일 옆에 기록을 저장하는 방식은 아닙니다. 실제 위치는 다음과 같습니다.

```text
%LOCALAPPDATA%\DailyPlayPortable\2.6\
├─ app\       실행에 필요한 파일
└─ data\      체크·설정·일정·복구 기록
```

탐색기 주소창에 위 경로를 입력해 열 수 있습니다. EXE를 옮기거나 다시 받아도 같은 Windows 계정에서는 같은 2.6 폴더를 사용합니다. 개발본이나 다른 설치판의 기록을 자동으로 가져오지 않습니다.

## 기본 조작

- **미니바**: 게임별 진행 상황을 확인하고, **알림판 상세** 또는 **달력**을 엽니다.
- **체크리스트**: 완료 체크·해제, 진행 수치 증가·감소, 항목 추가·수정을 사용합니다.
- **일정**: 시작·종료 시각과 출처를 확인합니다. 예상 일정은 확정 공지와 구분해서 확인하세요.
- **설정**: 테마, 창 표시, 로그인 시 자동실행, 온라인 일정 자동 갱신 등을 설정하고 저장합니다.
- **종료**: Windows 알림 영역의 DAILY PLAY 메뉴에서 종료합니다. 창만 닫는 것과 앱 종료는 다를 수 있습니다.

## 화면인식 켜기·끄기

1. **설정 → 게임 화면인식**을 엽니다.
2. 화면인식·알림판 연동과 지원 게임을 선택합니다.
3. **화면인식 자동반영**을 켜고 동의 내용을 확인합니다.
4. 나머지 변경은 **설정 저장**으로 적용합니다.
5. 지원 게임을 전면에 놓고 인식 대상 화면을 표시합니다.

최초 기본값은 OFF입니다. 켜기·끄기와 동의 상태는 저장되므로, 한 번 켜면 다음 실행에도 유지될 수 있습니다. 중지하려면 같은 설정에서 자동반영을 끄세요.

젠레스 존 제로·소녀전선2: 망명이 정식 자동반영 대상입니다. 게임 화면·배율·해상도에 따라 인식하지 못하거나 잘못 읽을 수 있습니다. 수동으로 바꾼 값은 해당 회차에서 우선하며, 다시 자동반영을 허용하려면 항목의 **자동 관리로 복귀**를 사용합니다.

## 백업과 새 버전

앱을 완전히 종료한 뒤 `%LOCALAPPDATA%\DailyPlayPortable\2.6\data` 폴더 전체를 별도 위치에 복사해 보관하세요. `planner.json` 하나만이 아니라 백업·복구 자료도 함께 보존해야 합니다. 추가 데이터 연결을 사용했다면 그 주소도 별도로 기록하세요.

새 버전은 [Releases](https://github.com/ERAE808/DAILY-PLAY/releases/latest)에서 확인하고 해당 버전의 이전 안내를 따르세요. 현재 공개 2.6에 자동 다운로드·자동 설치 또는 다른 버전으로의 기록 자동 이전을 보장하지 않습니다. 다른 판의 기록 폴더를 임의로 합치거나 실행 중 덮어쓰지 마세요.

## 제거

1. 로그인 시 자동실행을 사용했다면 설정에서 해제하고 저장합니다.
2. Windows 알림 영역 메뉴에서 앱을 종료합니다.
3. 기록을 보관하려면 `data` 폴더 전체를 먼저 백업합니다.
4. 내려받은 EXE를 삭제합니다. EXE 삭제만으로 사용자 폴더의 기록이 없어지지는 않습니다.
5. 기록까지 지우려는 경우에만 `%LOCALAPPDATA%\DailyPlayPortable\2.6` 폴더를 직접 삭제합니다.

사용자가 별도로 내보내거나 백업한 파일은 해당 위치에 남습니다. 자동실행 항목이 남아 있다면 `shell:startup`에서 `DailyPlay-GameChecklist.lnk`를 확인할 수 있습니다.

## 파일 일치 확인

PowerShell에서 내려받은 파일 위치로 이동한 후 다음 명령을 실행합니다.

```powershell
Get-FileHash -LiteralPath .\DAILY-PLAY-2.6.exe -Algorithm SHA256
```

결과를 [SHA256SUMS.txt](../SHA256SUMS.txt)와 비교합니다. 대소문자는 무관합니다. 해시는 게시된 파일과의 일치 여부를 확인하는 값이며, 안전성 인증이나 게시자 서명을 대신하지 않습니다.

## 실행 문제

- 파일 변경·누락 오류가 나면 기존 기록을 백업하고 오류 문구를 제보하세요. `app` 안의 파일을 임의로 수정하면 무결성 검사로 실행이 막힐 수 있습니다.
- 추가 데이터 연결 설정을 바꾼 뒤 재실행 오류가 생기면 기록을 보존하고 제보하세요. 이 설정은 앱 구성 파일을 변경하므로 공개 2.6의 무결성 검사와 충돌할 가능성이 있습니다.
- Windows 보안 경고가 발생하면 다운로드 출처와 해시를 확인하세요. 백신·보안 기능을 끄거나 관리자 권한으로 강제 실행하는 방식은 권장하지 않습니다.
- Windows 문자 인식 언어 오류는 Windows의 한국어 언어 기능을 확인하세요.
