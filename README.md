# DAILY PLAY · 데일리플레이

여러 게임의 일일·주간 할 일과 이벤트 일정을 한곳에서 관리하는 Windows용 데스크톱 프로그램입니다.

**[실행파일 다운로드](https://github.com/ERAE808/DAILY-PLAY/releases/latest)** · **[사용 안내](docs/USAGE.md)** · **[개인정보·권한·외부 통신](docs/PRIVACY.md)**

## 다운로드

현재 공개 파일은 **2.6 · `DAILY-PLAY-2.6.exe`**입니다.

- [2.6 실행파일 받기](https://github.com/ERAE808/DAILY-PLAY/releases/download/DAILYPLAY/DAILY-PLAY-2.6.exe)
- [2.6 릴리스 설명](https://github.com/ERAE808/DAILY-PLAY/releases/tag/DAILYPLAY)
- [SHA-256 확인값](SHA256SUMS.txt)

Releases의 **Assets**에서 EXE를 선택하세요. `Source code (zip/tar.gz)`는 저장소 자료의 압축파일이며, 실행용 패키지나 제품 소스 공개본이 아닙니다.

현재 2.6 릴리스는 임시 배포로 게시된 파일입니다. 이 안내 정비는 새 실행파일 출시나 전체 기능 검증 완료를 의미하지 않습니다.

## 할 수 있는 일

| 화면·기능 | 사용 방법 |
|---|---|
| 미니바 | 게임별 진행 상황을 보고 체크하거나 알림판 상세 열기 |
| 알림판·체크리스트 | 일일·주간·특별퀘스트의 완료 여부와 수치를 직접 수정 |
| 달력 | 게임 일정과 마감 확인 |
| 온라인 일정 | 공지·일정 자료를 갱신하고 출처 확인 |
| 화면인식 자동반영 | 동의 후 지원 게임의 전면 화면에서 진행도 판독 |
| 설정 | 표시·테마·자동실행·온라인 갱신·화면인식 설정 |

게임 목록: 명조, 명일방주: 엔드필드, 젠레스 존 제로, 소녀전선2: 망명, 트릭컬 리바이브.

현재 공개판의 정식 화면인식 자동반영 대상은 **젠레스 존 제로·소녀전선2: 망명**입니다. 게임 목록 전체가 자동인식을 지원하는 것은 아닙니다. 수동 체크·수치 수정도 사용할 수 있습니다.

## 처음 사용하기

1. Releases에서 EXE를 내려받아 실행합니다.
2. 처음 실행하면 현재 Windows 사용자 폴더에 필요한 파일을 풀고 미니바를 엽니다.
3. 미니바의 **알림판 상세**에서 게임별 할 일을 확인합니다.
4. 필요한 항목을 직접 체크하거나 수치를 바꿉니다.
5. 화면인식을 사용하려는 경우에만 **설정 → 게임 화면인식**에서 대상과 동의를 확인합니다.

실행 경로·백업·종료·제거 방법은 [사용 안내](docs/USAGE.md)를 참고하세요.

## 실행 환경과 확인할 점

- Windows 데스크톱용입니다. Windows PowerShell 5.1과 .NET Framework 4.x 기반 구성, 일부 실행 경로에는 Windows Script Host를 사용합니다.
- 화면인식에는 Windows OCR 언어 기능이 필요합니다. 한국어 인식에 문제가 있으면 Windows 한국어 언어 기능을 확인하세요.
- 공개 EXE는 **코드 서명이 없는 파일**입니다. Windows에서 게시자 확인 또는 보안 경고가 표시될 수 있습니다. 보안 기능을 끄는 방법은 안내하지 않습니다.
- 모든 PC·해상도·게임 화면에서의 정상 동작과 인식 정확도를 보장하지 않습니다. 일정은 원문 공지와 게임 안의 표시도 확인하세요.
- 현재 파일의 새 PC 실행·기록 저장·재시작을 이번 문서 정비에서 다시 시험하지 않았습니다.

## 정보 처리

체크·설정·복구 기록은 PC에 저장됩니다. 화면인식은 기본 OFF이며, 동의 후 켜면 게임 화면에 보이는 정보가 PC 안에서 처리됩니다. 일정 조회에는 인터넷 연결을 사용합니다.

저장 항목, 접속 대상, 화면인식의 처리 범위와 끄는 방법은 [개인정보·권한·외부 통신 안내](docs/PRIVACY.md)에 설명했습니다.
